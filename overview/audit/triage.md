# Triage of P1's open audit items

This table tracks the open status of every P1 item from the audit of 2026-10-13 ([`findings.json`](findings.json)): each item that A-31 lists, and each other finding with a P1 part. A row's Status changes here when the item closes, and the closure itself is recorded in [`closures.md`](closures.md). The audit files are not edited.

The per-item fixes the audit points to for A-31 (`_work/phase12/results/audit-p1.json`, 2026-10-09) are not in this repository. Each fix below is taken from the observation text of A-31 or of the finding named in the row. Line numbers were re-checked on main on 2026-11-24; where they moved since the audit's commit (`e539aa6`), the row gives the current line.

## Classes

- **Mechanical.** The fix corrects a statement, a pin or a file so that it matches what the repo already does. It changes no threat, requirement, VE allocation or architecture decision, so it needs no owner decision: the row names the file or line to fix and the check that keeps it fixed.
- **Owner decision.** The fix is a design change: it changes a threat, a requirement, a VE (its criteria or allocation) or an architecture decision, or it picks between methods with different costs. The options and their consequences are in [`owner-decisions.md`](owner-decisions.md); the item stays open until the owner records a decision there and the change lands.
- **Closed.** Closed since the audit, with the closure recorded in [`closures.md`](closures.md).
